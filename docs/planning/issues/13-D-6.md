# libs: calloc size overflow, realloc(p,0) leak, readline breaks for buffers > 256 bytes

**Affects:** release v2.42 and `develop` @ ec229f9 (r2.x, default build)
**Found by:** code review of v2.42 plus runtime tests in MAME (`rosco_m68k_010`); details in docs/planning/tests/ (branch `planning/session-docs` on maarten-boot/rosco_m68k)
**Status:** Confirmed in MAME (calloc(0x10000,0x10001) returned a block; readline with 280 chars into a 300-byte buffer returned 24 and overwrote the start).
**Review IDs:** D-6, D-11

## Description
- **D-6** `calloc` multiplies without an overflow check; `realloc(ptr, 0)` allocates a new block and never frees `ptr`.
- **D-11** `readline` uses a `uint8_t` index, which wraps at 256; when the buffer fills it returns `buf_size` instead of the stored length.

## Where (develop @ ec229f9)
- `code/software/libs/src/shmall/rosco_m68k.cpp:176`
- `code/software/libs/src/machine/basicio.c:24`

## How to reproduce
`tests/libtest/`, `tests/inputtest/` + `mame/input_harness.py` (types into the console over a socket).
