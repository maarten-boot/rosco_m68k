# develop: `make MAME=true` fails with -Werror=unused-label in stage2/main2.c

**Affects:** `develop` @ ec229f9 only (not v2.42)
**Found by:** code review of v2.42 plus runtime tests in MAME (`rosco_m68k_010`); details in docs/planning/tests/ (branch `planning/session-docs` on maarten-boot/rosco_m68k)
**Status:** Confirmed by building develop @ ec229f9 with the roscopeco/rosco_m68k image (m68k-elf-rosco-gcc 13.3.1).
**Review IDs:** U-1

## Description
```
main2.c:228:1: error: label 'have_kernel' defined but not used [-Werror=unused-label]
```
In the MAME configuration the SD/IDE loaders that jump to `have_kernel` are compiled out, so the label is unused.

## Where (develop @ ec229f9)
- `code/firmware/rosco_m68k_firmware/stage2/main2.c:228`

## How to reproduce
`make MAME=true BOARD_ROM_SIZE=256KB all` in code/firmware/rosco_m68k_firmware.

## Proposed fix
Guard the label with the same `#if` as its users, or mark it `__attribute__((unused))`.
